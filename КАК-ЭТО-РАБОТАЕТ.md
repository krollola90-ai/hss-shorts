# Как устроен наш монтаж — полное объяснение

Простым языком: из чего состоит система, как по ней проходит одно видео, что такое GitHub и
как каждый день расширять систему.

---

## 1. Общая картина: три части

Представь маленькую студию монтажа.

| Часть | Аналогия | Что делает | Где |
|---|---|---|---|
| **Google Drive** | **склад** | исходники, готовые ролики, твоя библиотека (музыка, звуки, фото, футажи) | папка `HSS Content` на твоём Диске |
| **GitHub** (репозиторий `hss-shorts`) | **мастерская с инструкциями** | всё, что знает и умеет монтаж: шаблоны рубрик, стили, шрифты, звуки, программа монтажа, «Голос Марка», история каждого видео | github.com/krollola90-ai/hss-shorts |
| **Claude** (я) | **монтажёр** | понимаю, что ты сказал, режу, выстраиваю логику, подбираю визуалы, рендерю, учусь на твоих правках | чат в приложении Claude |

Ещё есть **облачный компьютер**: в каждом чате мне выдают временный компьютер в облаке. На нём
стоят программы монтажа, там я режу и рендерю. Когда чат закрывается, этот компьютер стирается.
**Поэтому всё важное должно лежать в GitHub или на Диске**, а не «у меня в голове»: каждый новый
чат начинается с чистого компьютера, который первым делом скачивает мастерскую из GitHub.

```
 ТЫ                    СКЛАД (Google Drive)            МАСТЕРСКАЯ (GitHub)
 снял видео  ───────►  01_Входящие/<рубрика>
                                 │                         шаблоны, стили, звуки,
 пишешь «монтаж» ─► Claude ◄─────┘ забирает видео           шрифты, Голос Марка,
                       │  ◄──────────────────────────────── программа монтажа
                       │  режет, логика, визуалы, рендер
                       │  ───── сохраняет историю видео и всё новое ─────►
 получаешь ролик ◄─────┘  (в чат и в 02_Готово)
```

## 2. Путь одного видео — по шагам

1. **Ты снимаешь** и кидаешь файл в `01_Входящие/<рубрика>` (Вакансии, Новости, Мысли…).
   Можно рядом положить заметку `.txt` с тем же именем: «главное — фраза в конце».
2. **Открываешь новый чат** с репозиторием `hss-shorts` и пишешь **«монтаж»**.
3. **Автоматически**: облачный компьютер скачивает мастерскую и ставит программы (`setup.sh`).
4. **Я нахожу видео** во Входящих через коннектор Google Drive и скачиваю его.
5. **Делаю рабочую копию**: переворачиваю в вертикаль 1080×1920, уменьшаю тяжёлый 4K, вытаскиваю звук.
6. **Расшифровка**: ElevenLabs (точно, платно по кредитам) или Whisper (бесплатно, чуть хуже).
   Получаю каждое слово с точным временем.
7. **Понимаю, что это за видео**: рубрика, главная мысль, хук. Читаю «Голос Марка» —
   что ты обычно говоришь, что резать, что беречь.
8. **Чистка и логика**: вырезаю паразиты, паузы, дубли, разговоры за кадром; переставляю блоки
   в понятный порядок по шаблону рубрики.
9. **Для личных рубрик** (мысли, мотивация, о себе…): присылаю тебе **список визуалов**,
   создаю папку на Диске, ты кидаешь фото и видео, я их забираю.
10. **План монтажа**: хук, карточки с цифрами и списками, эмодзи, фото и видеовставки, зумы, звуки,
    музыка — всё с точностью до слова.
11. **Сборка и проверка**: собираю кадры, сам смотрю их, чтобы ничего не закрывало лицо.
12. **Превью** → твои правки обычными словами → **финальный рендер**: громкость до стандарта
    соцсетей (−14 LUFS), автоматическая проверка качества.
13. **Готовый ролик**: в чат (и в `02_Готово`, если на ноутбуке стоит «Диск для компьютера»).
14. **Обучение**: считаю цифры твоей речи, дописываю наблюдения в «Голос Марка», сохраняю всё
    в GitHub. Следующий чат уже знает больше.

## 3. Что такое GitHub — простыми словами

- **Репозиторий** — это папка с файлами, у которой есть **вся история изменений**. Как Google Диск,
  только каждое изменение сохраняется отдельной «точкой», и к любой можно вернуться.
- **Коммит** — одна сохранённая точка с подписью, что изменилось: «добавил стиль Неон».
- **Push** — отправить сохранённое с облачного компьютера на GitHub, чтобы оно не стёрлось.
- **Зачем он нам**: облачный компьютер одноразовый, а GitHub вечный. Всё, чему мы научили
  монтаж, живёт там. Новый чат за секунды получает всё накопленное.
- **Почему не всё на Диске**: GitHub хранит **историю** и подходит для текстовых файлов с
  настройками и кодом. Тяжёлые видео и музыка у него лимитированы — их место на Диске.
- **Ничего не сломается навсегда**: если что-то пошло не так, можно откатиться к любой прошлой точке.

### Рубрика (`formats/<имя>.json`)

Отвечает на вопрос «**как рассказать**». Пример `formats/vacancy.json`:

```json
{
  "title": "Вакансия",
  "status": "approved",                       ← проверена на реальных видео
  "style": "styles/white-minimal-fast.json",  ← каким стилем оформлять
  "target_seconds": [30, 60],                 ← желаемая длина
  "structure": ["хук: город + ставка", "что за работа", "кого ищем", "график",
                "зарплата", "условия", "срочность", "концовка"],
  "overlays": "stat для денег, list для условий, card для локации",
  "music": null,                              ← без музыки
  "ending": "Уся контактна інформація у профілі",
  "visuals": "auto"                           ← визуалы подбираю сам (brief = прошу у тебя)
}
```

Сейчас рубрик 9: вакансия ✅, новости, мысль, идея, о себе, влог, эдит, совет, ответ на вопрос.

### Стиль (`styles/<имя>.json`)

Отвечает на вопрос «**как выглядит**». Главные поля:

| Поле | Что меняет |
|---|---|
| `title` | название стиля по-русски |
| `font_family` | шрифт: Inter, Montserrat, Unbounded, Rubik, Manrope, Oswald, Nunito |
| `colors.accent` | главный цвет: активное слово, цифры, плашки |
| `colors.glass` | цвет и прозрачность карточек |
| `hook.*` | цвета плашек хука в начале |
| `captions.words_per_group` | сколько слов на экране сразу |
| `captions.uppercase` | капс или обычные буквы |
| `captions.font_size` | размер субтитров |
| `zoom.min_interval / max_interval` | как часто «наезды» камеры |
| `cuts.max_pause` | сколько паузы оставлять между словами (меньше = быстрее темп) |
| `audio.sfx_db / music_db` | громкость звуков и музыки |

### Звук (`assets/sfx/manifest.json`)

Каждый звук записан с длительностью и **моментом удара**, чтобы удар звука точно совпадал
с появлением карточки. `approved: true` — звук разрешён в монтаже.

### Проект (`projects/<рубрика-дата-тема>/`)

История одного видео: `transcript.json` (что ты сказал), `overrides.json` (что вырезано и в каком
порядке), `edit_plan.json` (все карточки, эмодзи, вставки со временем), `project.json` (рубрика и стиль).
Через месяц можно сказать «перемонтируй Тересин в жёлтом стиле» — и это делается без новой
расшифровки.

## 5. Как расширять систему

### Уровень 1 — просто скажи мне (без кода)

Пишешь обычными словами, я правлю нужные файлы, проверяю на кадрах и сохраняю в GitHub.

- «Сделай новый стиль: чёрный фон карточек, красный акцент, шрифт Unbounded, назови Ночь»
- «Сделай рубрику "Разбор зарплат": хук с цифрой, сравнение двух вакансий, вывод»
- «Для мыслей всегда без капса и с музыкой calm»
- «Добавь в библиотеку звуки из папки _Библиотека/Звуки»
- «Сделай новую анимацию субтитров, как в этом видео» (+ ссылка в Референсы)

**Лучше всего такие задачи делать в отдельном чате «развитие»**, не смешивая с монтажом конкретного
видео: так дешевле по лимиту и понятнее история изменений.

### Уровень 2 — пополнять склад (ты, без меня)

| Что | Куда на Диске | Потом скажи мне |
|---|---|---|
| музыка (Pixabay Music, YouTube Audio Library) | `_Библиотека/Музыка` | «забери музыку, разложи по настроениям» |
| звуки | `_Библиотека/Звуки` | «добавь новые звуки в библиотеку» |
| свои стикеры, логотипы (PNG с прозрачным фоном) | `_Библиотека/Стикеры и эмодзи` | «добавь стикеры» |
| свои футажи (город, работа, жизнь) | `_Библиотека/Футажи` | — я предложу их сам, когда подойдут |
| ролики, которые нравятся по стилю | `_Библиотека/Референсы` | «сделай стиль как в референсе 3» |

### Уровень 3 — править самому на github.com

Любой файл можно открыть на github.com → значок карандаша → изменить → **Commit changes**.
Удобно для мелочей: поменять цвет в стиле, текст концовки в рубрике, дописать правило в
`docs/voice.md`. Новый стиль = открыть любой файл в `styles/`, скопировать текст, создать новый
файл с другим именем и поменять `title` и цвета.

### Что требует кода (делаю я)

Новые **виды** анимаций и элементов: анимации субтитров, дизайны карточек, переходы, плашки рубрик,
монтаж под бит, «не повторяться». Это изменения в `scripts/build_comp.py` — по плану в `docs/roadmap.md`.

## 6. Ежедневная рутина роста (15–30 минут)

1. **Контент**: запиши 1–3 видео → во Входящие → «монтаж».
2. **Склад**: 3–5 новых треков, звуков или футажей в `_Библиотека`.
3. **Референс**: один ролик, который зацепил → в `Референсы` + одна строка: что понравилось.
4. **Развитие**: одна задача из `docs/roadmap.md` в отдельном чате («сделай следующий пункт плана»).
5. **Цифры**: раз в неделю — просмотры и досмотры роликов. Я свяжу их с пресетами и скажу, что
   заходит лучше.

## 7. Автоматизация: что уже само, что дальше

**Уже автоматически**: установка программ, рабочая копия видео, расшифровка, вырезка паразитов и
пауз, порядок по шаблону, субтитры, звуки на событиях, громкость, проверка качества, анализ речи,
сохранение истории.

**Дальше по плану**:
- 8 анимаций субтитров и 8 дизайнов карточек → 20, потом 100 пресетов;
- витрина пресетов и режим «не повторяться»;
- плашки рубрик и переходы;
- монтаж под бит;
- статистика по пресетам;
- бот, когда процесс устоится.

## 8. Правила, чтобы всё работало

- **Одно видео = один новый чат.** Дешевле по лимиту Claude, и чат не «перегружается».
- **Папка `01_Входящие` открыта по ссылке**, иначе я не смогу скачать видео.
- **Место на Диске**: после публикации исходник — в архив или удалить (1 минута 4K ≈ 0,5 ГБ).
- **Кредиты ElevenLabs** видны в их кабинете; кончились — работаю на бесплатном Whisper.
- **Права**: в ролик — свои съёмки и бесплатные библиотеки; чужие видео и фото знаменитостей
  ищешь ты и решаешь сам, публиковать ли.
