# Музыка

Папки по настроению: `calm/` (спокойная, для «Мысли»), `upbeat/` (бодрая, для «Идеи» и влогов),
`emotional/` (эмоциональная), `phonk/` (агрессивная, для эдитов), `lofi/` (фон).

Только треки с бесплатной коммерческой лицензией (Pixabay Music, YouTube Audio Library).
