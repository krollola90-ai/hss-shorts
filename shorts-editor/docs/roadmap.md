# План развития конструктора

## Как устроено (цель)

```
Видео во «Входящие/<рубрика>» ─► «монтаж» в новом чате
   ─► рубрика (formats/) + голос Марка (docs/voice.md)  →  логика, вырезки, порядок
   ─► пресет оформления (styles/ + детали конструктора)  →  вид
   ─► визуальный слой: цифры, списки, эмодзи, картинки, переходы, музыка
   ─► превью → «ок» → готовое видео (чат + 02_Готово)
```

Пресет = шрифт × палитра × анимация субтитров × дизайн карточек × переходы × эмодзи-набор × темп.
